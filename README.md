# Day 13: Inventory Management System

## Overview
This project is part of the inventory management system training, focusing on robust stock validation, strict adherence to the 10,000-unit stock cap, and bulletproof error handling.

## Features
- *Stock Cap Enforcement:* Prevents any return or restock action that exceeds the maximum limit of 10,000 units.
- *Safe Integer & Quantity Validation:* Validates that operations use safe numbers and correct boundaries.
- *Data Integrity:* Ensures business metrics and totals remain preserved and accurate upon operational refusals.
