## Questions for the Mentor

1. Difference between let and const:
let allows me to change a variable's value. const prevents reassignment.

2. Difference between = and ===:
= assigns a value. === compares two values and their types.

3. What is the output?
"5" + 1 gives "51" because it joins a string and a number.
Number("5") + 1 gives 6 because the string is converted to a number.
