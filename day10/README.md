# Day 10 - Advanced Inventory Management System

## Overview
A comprehensive JavaScript inventory tracking application that manages multiple products (Notebook and Eraser), processes sales, restocks, and returns, and strictly enforces rigorous guard conditions and capacity limits.
## Key Features
- *Pure Unit Tracking:* Complete removal of any financial indicators, prices, or currency symbols.
- *Guard Validation:* Validates integer-only quantities within the safe transactional range (1 to 1000).
- *Capacity Control:* Enforces a strict maximum stock limit of 10,000 units.
- *Continuous Execution Flow:* Simulates multi-product lifecycles seamlessly without state corruption.
## Project Structure
- script.js: Core implementation of inventory logic and full continuous flow scenarios.
- test.results.md: Automated boundary and edge-case unit tests.
- debugging_notes.md: Detailed logs of investigations, bug fixes, and retest results.
- console_output.png: Verification  of successful console execution.
