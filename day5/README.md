# Day 5 - Stock Desk Project

This is my submission for Day 5 of the Stock Desk project. In this part, I focused on Evidence-Based Testing, checking helper boundaries, and making sure the system state remains completely unchanged when operations are rejected (Zero Mutation).

## Files Included
- stock-desk.js: The main JavaScript code with all functions, boundary tests, and product sequences.
- README.md: Project overview and instructions.
- test-results.md: Documented test outputs and boundary checks.
- debug-notes.md: Notes on issues faced and how I fixed them.

## How to Run
To run the code, open your terminal and type:
\`\`\`bash
node stock-desk.js
\`\`\`
