# Stock Desk Inventory System Day 8 UI

## Overview
A web-based user interface for the Stock Desk inventory system built using pure HTML5, CSS3, and JavaScript (ES6+). It allows users to manage inventory operations (Sell, Restock, Return) dynamically with real-time table rendering and explicit validation.

## Features
- *Dynamic Table Rendering*: Automatically updates stock levels, net sold items, net sales, and total inventory value.
- *Robust Validation*: Ensures positive whole numbers for quantities and prevents invalid operations (e.g., selling or returning more than available stock/sales).
- *Clean UI*: Responsive layout designed without any currency symbols for clean data representation.

## File Structure
- index.html: Main HTML structure.
- styles.css: CSS styling and responsive layout.
- app.js: JavaScript logic, state management, and DOM event listeners.
- README.md: Project documentation.
- test-results.md: Browser test cases and results.
- debug-notes.md: Documentation of resolved syntax and formatting issues.
