
# Stock Desk UI - Day 9 Checkpoint

## Overview
A reliable and accessible stock management interface built with plain HTML, CSS, and JavaScript.

## Run Steps
1. Open the day9-ui folder.
2. Open index.html in a modern browser (Edge or Chrome).
3. Select a product, input a quantity, and perform actions (Sell, Restock, Return).
